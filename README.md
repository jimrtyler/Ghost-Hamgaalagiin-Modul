# 👻 Ghost Аюулгүй Байдлын Модуль
**PowerShell Суурилсан Windows болон Azure Аюулгүй Байдал Бэхжүүлэх Багаж**

> **Windows төгсгөлийн цэгүүд болон Azure орчинд идэвхтэй аюулгүй байдлын бэхжүүлэлт.** Ghost нь шаардлагагүй үйлчилгээ болон протоколуудыг идэвхгүй болгосноор нийтлэг довтолгооны векторуудыг бууруулахад туслах PowerShell суурилсан бэхжүүлэх функцуудыг өгдөг.

## ⚠️ Чухал Анхааруулга

**ТУРШИЛТ ШААРДЛАГАТАЙ**: Үргэлж эхлээд үйлдвэрлэлийн бус орчинд Ghost-г турших. Үйлчилгээг идэвхгүй болгох нь хууль ёсны бизнесийн функцуудад нөлөөлж болно.

**ЯМАР Ч БАТАЛГАА АЛГА**: Ghost нь ердийн довтолгооны векторуудыг онилж байгаа ч ямар ч аюулгүй байдлын багаж бүх довтолгоог сөргөөж чадахгүй. Энэ бол иж бүрэн аюулгүй байдлын стратегийн нэг бүрэлдэхүүн хэсэг юм.

**ҮЙЛДВЭРЛЭЛИЙН НӨЛӨӨ**: Зарим функцууд нь системийн ажиллагаанд нөлөөлж болно. Байршуулахаас өмнө тохиргоо бүрийг анхааралтай хянана уу.

**МЭРГЭЖЛИЙН ҮНЭЛГЭЭ**: Үйлдвэрлэлийн орчинд тохиргоонууд танай байгууллагын хэрэгцээтэй нийцэж байгаа эсэхийг баталгаажуулахын тулд аюулгүй байдлын мэргэжилтнүүдтэй зөвлөлд.

## 📊 Аюулгүй Байдлын Дүр Төрх

Ransomware хор хөнөөл **2025 онд 57 тэрбум доллар**-т хүрч, судалгаанаас харахад олон амжилттай довтолгоо нь Windows-ын үндсэн үйлчилгээ болон буруу тохиргоонуудыг ашигладаг. Нийтлэг довтолгооны векторууд:

- **Ransomware тохиолдлын 90%** нь RDP мөлжлөгтэй холбоотой
- **SMBv1 эмзэг байдал** нь WannaCry болон NotPetya зэрэг довтолгоог боломжтой болгосон
- **Баримт бичгийн макро** нь хорт программын үндсэн хүргэх арга хэвээр байна
- **USB суурилсан довтолгоонууд** агаарын зай бүхий сүлжээнүүдэд чиглэсээр байна
- **PowerShell буруу хэрэглээ** сүүлийн жилүүдэд мэдэгдэхүйц нэмэгдсэн

## 🛡️ Ghost Аюулгүй Байдлын Функцууд

Ghost нь **16 Windows бэхжүүлэх функц** болон **Azure аюулгүй байдлын интеграци**ыг өгдөг:

### Windows Төгсгөлийн Цэг Бэхжүүлэлт

| Функц | Зорилго | Анхаарах зүйл |
|----------|---------|----------------|
| `Set-RDP` | Remote Desktop хандалтыг удирдах | Алсын удирдлагад нөлөөлж болно |
| `Set-SMBv1` | Хуучин SMB протоколыг хянах | Маш хуучин системд шаардлагатай |
| `Set-AutoRun` | AutoPlay/AutoRun-г хянах | Хэрэглэгчийн тав тухтай байдалд нөлөөлж болно |
| `Set-USBStorage` | USB хадгалах төхөөрөмжийг хязгаарлах | Хууль ёсны USB хэрэглээнд нөлөөлж болно |
| `Set-Macros` | Office макро гүйцэтгэлийг хянах | Макро идэвхжүүлсэн баримт бичигт нөлөөлж болно |
| `Set-PSRemoting` | PowerShell алсын холболтыг удирдах | Алсын удирдлагад нөлөөлж болно |
| `Set-WinRM` | Windows Remote Management-г хянах | Алсын удирдлагад нөлөөлж болно |
| `Set-LLMNR` | Нэр шийдвэрлэх протоколыг удирдах | Ерөнхийдөө идэвхгүй болгох аюулгүй |
| `Set-NetBIOS` | TCP/IP дээрх NetBIOS-г хянах | Хуучин програмуудад нөлөөлж болно |
| `Set-AdminShares` | Удирдлагын хуваалцааг удирдах | Алсын файл хандалтад нөлөөлж болно |
| `Set-Telemetry` | Өгөгдөл цуглуулалтыг хянах | Оношилгооны чадварт нөлөөлж болно |
| `Set-GuestAccount` | Зочин данс удирдах | Ерөнхийдөө идэвхгүй болгох аюулгүй |
| `Set-ICMP` | Ping хариултыг хянах | Сүлжээний оношилгоонд нөлөөлж болно |
| `Set-RemoteAssistance` | Remote Assistance-г удирдах | Тусламжийн ширээний үйлдэлд нөлөөлж болно |
| `Set-NetworkDiscovery` | Сүлжээ илрүүлэлтийг хянах | Сүлжээ хөтлөлтөнд нөлөөлж болно |
| `Set-Firewall` | Windows Firewall-г удирдах | Сүлжээний аюулгүй байдалд чухал |

### Azure Үүлэн Аюулгүй Байдал

| Функц | Зорилго | Шаардлага |
|----------|---------|--------------|
| `Set-AzureSecurityDefaults` | Үндсэн Azure AD аюулгүй байдлыг идэвхжүүлэх | Microsoft Graph зөвшөөрөл |
| `Set-AzureConditionalAccess` | Хандалтын бодлогыг тохируулах | Azure AD P1/P2 лиценз |
| `Set-AzurePrivilegedUsers` | Давуу эрхт дансуудыг шалгах | Global Admin зөвшөөрөл |

### Аж Ахуйн Нэгжийн Байршуулалтын Сонголтууд

| Арга | Хэрэглээний Тохиолдол | Шаардлага |
|--------|----------|--------------|
| **Шууд Гүйцэтгэл** | Туршилт, жижиг орчин | Орон нутгийн админ эрх |
| **Group Policy** | Домэйн орчин | Домэйн админ, GP удирдлага |
| **Microsoft Intune** | Үүлээр удирдагдах төхөөрөмж | Intune лиценз, Graph API |

```powershell
Set-Ghost -SMBv1 -AutoRun -Macros

# Өөрчлөлтийг хянах
Get-Ghost
```

## 🔍 Функцийн Дэлгэрэнгүй

### Үндсэн Бэхжүүлэх Функцууд

#### Сүлжээний Үйлчилгээ
- **RDP**: Алсын ширээний хандалтыг хаах эсвэл портыг санамсаргүй болгох
- **SMBv1**: Хуучин файл хуваалцах протоколыг идэвхгүй болгох
- **ICMP**: Тагнуулын зорилгоор ping хариултыг хориглох
- **LLMNR/NetBIOS**: Хуучин нэр шийдвэрлэх протоколуудыг хаах

#### Програмын Аюулгүй Байдал
- **Макро**: Office програмуудад макро гүйцэтгэлийг идэвхгүй болгох
- **AutoRun**: Сольж болох медиаас автомат гүйцэтгэлийг хориглох

#### Алсын Удирдлага
- **PSRemoting**: PowerShell алсын сессийг идэвхгүй болгох
- **WinRM**: Windows Remote Management-г зогсоох
- **Remote Assistance**: Алсын тусламжийн холболтыг хаах

#### Хандалтын Хяналт
- **Admin Shares**: C$, ADMIN$ хуваалцааг идэвхгүй болгох
- **Guest Account**: Зочин дансны хандалтыг идэвхгүй болгох
- **USB Storage**: USB төхөөрөмжийн хэрэглээг хязгаарлах

### Azure Интеграц
```powershell
# Azure tenant-тэй холбогдох
Connect-AzureGhost -Interactive

# Аюулгүй байдлын анхдагч тохиргоог идэвхжүүлэх
Set-AzureSecurityDefaults -Enable

# Нөхцөлт хандалтыг тохируулах
Set-AzureConditionalAccess -BlockLegacyAuth -RequireMFA

# Давуу эрхт хэрэглэгчдийг шалгах
Set-AzurePrivilegedUsers -AuditOnly
```

### Intune Интеграц (v2-д шинэ)
```powershell
# Intune-тэй холбогдох
Connect-IntuneGhost -Interactive

# Intune бодлогоор байршуулах
Set-IntuneGhost -Settings @{
    RDP = $true
    SMBv1 = $true
    USBStorage = $true
    Macros = $true
}
```

## 🎯 Довтолгооны Хувилбарын Жишээ

Ghost нь ердийн довтолгооны векторуудыг онилж байгаа ч тодорхой урьдчилан сэргийлэлт нь зөв хэрэгжүүлэлт, туршилтаас хамаарна:

### WannaCry Хэлбэрийн Довтолгоо
- **Бууруулалт**: `Set-Ghost -SMBv1` эмзэг протоколыг идэвхгүй болгоно
- **Анхаарах зүйл**: Ямар ч хуучин систем SMBv1 шаардахгүй байгаа эсэхийг баталгаажуулах

### RDP Суурилсан Ransomware
- **Бууруулалт**: `Set-Ghost -RDP` алсын ширээний хандалтыг хаана
- **Анхаарах зүйл**: Өөр алсын хандалтын аргууд шаардлагатай байж болно

### Баримт Суурилсан Malware
- **Бууруулалт**: `Set-Ghost -Macros` макро гүйцэтгэлийг идэвхгүй болгоно
- **Анхаарах зүйл**: Хууль ёсны макро идэвхжүүлсэн баримт бичигт нөлөөлж болно

### USB Дамжуулсан Аюул
- **Бууруулалт**: `Set-Ghost -USBStorage -AutoRun` USB функцийг хязгаарлана
- **Анхаарах зүйл**: Хууль ёсны USB төхөөрөмжийн хэрэглээнд нөлөөлж болно

## 📚 Шилдэг Дадлага

### Байршуулалтын Өмнө
1. **Одоогийн Байдлыг Баримтжуулах**: Өөрчлөлтийн өмнө `Get-Ghost` ажиллуулах
2. **Анхааралтай Турших**: Үйлдвэрлэлийн бус орчинд баталгаажуулах
3. **Буцаах Төлөвлөгөө**: Тохиргоо бүрийг хэрхэн буцаахыг мэдэх
4. **Оролцогчдын Хянан Үзэх**: Бизнесийн нэгжүүд өөрчлөлтийг зөвшөөрч байгаа эсэхийг баталгаажуулах

### Байршуулалтын Үед
1. **Шатлалт Хандлага**: Эхлээд туршилтын бүлэгт байршуулах
2. **Нөлөөг Хянах**: Хэрэглэгчийн гомдол эсвэл системийн асуудалд анхаарах
3. **Асуудлыг Баримтжуулах**: Ирээдүйн лавлагааны тулд ямар нэг асуудлыг бүртгэх
4. **Өөрчлөлтийг Мэдээлэх**: Аюулгүй байдлын сайжруулалтын талаар хэрэглэгчдэд мэдэгдэх

### Байршуулалтын Дараа
1. **Тогтмол Үнэлгээ**: Тохиргоог баталгаажуулахын тулд үе үе `Get-Ghost` ажиллуулах
2. **Баримтжуулалтыг Шинэчлэх**: Одоогийн аюулгүй байдлын тохиргоог хадгалах
3. **Үр Дүнг Хянах**: Аюулгүй байдлын хэрэг явдлыг хянах

- **Ямар ч Баталгаа Алга**: Ghost нь ямар ч төрлийн баталгаагүйгээр "байгаа байдлаар" олгогдсон
- **Туршилт Шаардлагатай**: Үргэлж эхлээд үйлдвэрлэлийн бус орчинд турших
- **Мэргэжлийн Удирдамж**: Үйлдвэрлэлийн байршуулалтад аюулгүй байдлын мэргэжилтнүүдтэй зөвлөлдөх
- **Үйлдвэрлэлийн Нөлөө**: Зохиогчид ямар ч үйлдвэрлэлийн тасалдалд хариуцлага хүлээхгүй
- **Иж Бүрэн Аюулгүй Байдал**: Ghost бол бүрэн аюулгүй байдлын стратегийн нэг бүрэлдэхүүн хэсэг

### Дэмжлэг
- **GitHub Issues**: [Алдааны мэдээлэл өгөх эсвэл функц хүсэх](https://github.com/jimrtyler/Ghost/issues)
- **Баримтжуулалт**: Дэлгэрэнгүй тусламжийн тулд `Get-Help <function> -Full` хэрэглэх
- **Хамтын Нийгэм**: PowerShell болон аюулгүй байдлын хамтын нийгэмлэгийн форум

---

**🔒 Ghost-оор аюулгүй байдлын байр суурийг бэхжүүл - гэвч үргэлж эхлээд турш.**

```powershell
# Таамаглалгүйгээр үнэлгээгээр эхэлж
Get-Ghost
```

**⭐ Ghost танай аюулгүй байдлын байр суурийг сайжруулахад туслаж байвал энэ репозиторид од өг!**
